🤖 Prompt de Referencia para XOLO (Solo para Maestro)

Quiero aprender a combinar visión y movimiento para que el XGO no solo gire, sino que también se acerque a la pelota en Python. Explícame cómo un bucle while permite que el robot esté “pendiente” del objeto en tiempo real. ⚡ Puntos Esenciales de la Misión

🎓

Concepto Clave

Seguimiento Inteligente: Es la capacidad de un robot para observar un objeto y ajustar sus movimientos constantemente para no perderlo de vista, como un portero siguiendo el balón.

🔧

Habilidad Técnica

Usar la cámara inteligente para que el perro robot XGO persiga objetos de forma automática.

🧪

Experimentación

Probar con diferentes velocidades de acercamiento y distancias de frenado para entender las limitaciones del control reactivo.

🚨 Resolución Rápida de Problemas

  • Si los alumnos no pueden ingresar a Gnius Space: Activa XOLO SOS en xolo.gnius.club para continuar la misión sin interrumpir la clase.
  • Si el XGO no se mueve: Verificar que la batería esté cargada y el interruptor en ON. Revisar que el micro:bit esté bien conectado al escudo de expansión.
  • Si el lente no detecta la pelota: Asegurarse de que el lente esté en modo "Ball Tracking". Revisar que la iluminación sea uniforme y no haya reflejos fuertes.
  • Si hay errores en el código: Recordar a los estudiantes que XOLO puede ayudar a depurar. Pídeles que copien el error y se lo muestren a XOLO.

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a idear un proyecto en Python donde el XGO sea un “robot asistente deportivo” que persigue la pelota y se posiciona frente a ella como si fuera un jugador inteligente. Quiero que se acerque, frene a una distancia segura y mantenga el objeto centrado. Después genera el código en Python para ejecutarlo, de acuerdo a tu entrenamiento con el robot XGO y Micro:bit."

2. 🔬 Experimenta y descubre con tu programa:

  • ¿El XGO logra detenerse antes de tocar la pelota?
  • ¿Qué sucede si mueves la pelota muy rápido hacia los lados?
  • ¿Funciona igual el seguimiento con mucha luz que en la sombra?
  • ¿Cómo ayuda el control reactivo a que el robot no se pierda si la pelota se mueve?
  • ¿Por qué es importante establecer límites de seguridad cuando el robot se mueve solo?

¡Es hora de crear! Vamos a convertir al XGO en un verdadero asistente deportivo. El flujo es sencillo: primero ideen con XOLO cómo quieren que se comporte su robot, definan el VIBE, obtengan su GCS y pásenlo a MakeCode. Por ejemplo, podrían programarlo para que sea un defensa que no deja pasar la pelota o un delantero que la persigue por toda la cancha. Prueben primero en el simulador y, cuando estén listos, les entregaré el hardware. Recuerden las preguntas de experimentación para ver si su robot es realmente seguro. Si tienen errores o dudas, pregúntenle a XOLO, él los ayudará a depurar.
